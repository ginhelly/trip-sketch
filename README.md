# Trip Sketch

Планировщик поездок на своей карте. Вы сами рисуете точки и связи между ними
и вводите конкретные рейсы с датами и ценой, а приложение находит по ним
самые дешёвые или самые быстрые маршруты. Не сервис билетов: никаких данных
о расписаниях оно не знает, считает только по тому, что вы ввели.

Всё работает в браузере, без сервера и аккаунта. Проект сохраняется
автоматически в браузере и экспортируется в JSON.

## Как пользоваться

1. **Точки.** Найдите место в строке поиска или нажмите «+ Точка» и кликните
   по карте. Адрес и таймзона определяются сами, название можно поправить.
   Точки можно перетаскивать. Клик по точке выделяет её, «Редактировать»
   открывает диалог: название, таймзона, минимальная пересадка.
2. **Связи.** «+ Связь»: выберите исходную точку, затем конечную. Связь
   направленная: A → B и B → A это разные связи. «+ Точка со связью»
   создаёт сразу и новую точку, и связь до неё от выбранной.
3. **Рейсы.** В диалоге связи добавьте варианты проезда: название, цена,
   дата и местное время отправления и прибытия с таймзонами, заметка
   в Markdown. Расписания нет, каждый рейс это конкретный день и час,
   нужный на другой день нужно добавить отдельной карточкой
   (кнопка ⧉ копирует карточку). Галочка отключает рейс из расчёта,
   ошибки в карточке подсвечиваются.
4. **Маршрут.** В панели справа выберите начало, конец, время «не раньше»
   и критерий: самые дешёвые или самое раннее прибытие. «Рассчитать»
   показывает несколько вариантов, выбранный подсвечивается на карте.
   Начало отмечено на карте буквой A, конец буквой B. Если после расчёта
   что-то изменилось, результат помечается устаревшим.
5. **Долгая пересадка.** В диалоге точки переключите «Пересадка» на «Долгая»
   и добавьте варианты проживания или хранения с ценой за ночь или за час.
   Если ожидание в точке дольше 3 часов, в маршрут добавляется самый дешёвый
   подходящий вариант. Время вводить не нужно, оно берётся из маршрута.
6. **История.** Вкладка «История» показывает правки графа, клик по пункту
   возвращает состояние на тот момент. Ctrl+Z отменяет, Ctrl+Shift+Z
   повторяет. История живёт только в сессии и сбрасывается при новом проекте
   и импорте.
7. **Сохранение.** Автосохранение в браузере. Меню «Проект» экспортирует
   и импортирует JSON (в нём нет ключей и секретов).

Кнопка ⚙ открывает настройки: свои тайловые сервисы, сколько вариантов
маршрута показывать (по умолчанию 3), можно ли двигать точки и геокодер
(Photon или Nominatim). Подложку выбирает список «Подложка» на карте.
На телефоне панель справа становится нижней шторкой, её можно тянуть.

## Ограничения

- Время считается по абсолютным моментам с учётом таймзон. Для времени,
  которое при переводе часов встречается дважды, нужно выбрать смещение,
  несуществующее время отклоняется.
- Подложка Google Hybrid подключена по неофициальному адресу тайлов без
  ключа. Он может перестать работать, а использование может нарушать условия
  Google. Подложки OpenStreetMap подписаны атрибуцией.
- Внешние запросы: только тайлы карты и геокодер (Photon или Nominatim,
  у публичных серверов есть лимиты). Таймзона по координатам определяется
  в браузере без запросов, но у самых границ зон может ошибиться, тогда её
  можно задать вручную. Без сети карта и геокодер не работают, ручной ввод
  остаётся.
- Рёбра на карте это прямые схематичные дуги, а не настоящие дороги.
  Единица стоимости одна: «у.е.».

## Разработка

```bash
npm install
npm run dev       # разработка
npm test          # тесты (Vitest)
npm run build     # проверка типов и сборка в dist/
npm run preview   # посмотреть собранное
```

Расчёт маршрутов (`src/routing.ts`, `src/layover.ts`) не зависит от Vue
и карты и покрыт тестами.

## GitHub Pages

В репозитории: Settings → Pages → Source → «GitHub Actions». После этого
каждый пуш в `main` запускает `.github/workflows/deploy.yml`: тесты, сборка
и публикация. Сборка использует относительные адреса, поэтому работает
в подпапке `https://<пользователь>.github.io/<репозиторий>/`.
